# CrowdHeal (React + Vite)

Medical crowdfunding UI migrated from the original static HTML pages.

## Run locally

```bash
cd crowdheal-react
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## What’s included

- Home, campaigns, campaign detail + donation modal
- Login / signup (localStorage session)
- Create, edit, and dashboard for published campaigns
